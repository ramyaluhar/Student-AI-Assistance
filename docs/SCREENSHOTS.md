# 📸 Screenshots Description

Since this is a source-code deliverable, actual screenshots must be captured
after running the app locally (see `INSTALLATION_GUIDE.md`). Below is the
expected shot list with what each screen should demonstrate — useful both as
a capture checklist and for the GTU project report's "Screenshots" chapter.

| # | Screen                     | What it should show                                                                 |
|---|------------------------------|-----------------------------------------------------------------------------------------|
| 1 | Landing Page                 | Hero section, feature grid, light/dark toggle, Login/Register CTAs                     |
| 2 | Register Page                 | Registration form with validation states                                                |
| 3 | Login Page                    | Login form, "forgot" state N/A, link to Register                                        |
| 4 | Dashboard (light mode)        | Stat cards, Chart.js quiz trend line chart, attendance bar chart, task doughnut chart   |
| 5 | Dashboard (dark mode)         | Same as #4 with dark theme applied — demonstrates theme toggle                          |
| 6 | AI Chat Assistant             | Chat history sidebar + active conversation with a real Gemini response                  |
| 7 | Notes — Upload                | Upload form with a PDF selected, notes list on the left                                 |
| 8 | Notes — AI Summary            | A note's generated summary + key points panel                                           |
| 9 | Quiz Generator — Setup        | Topic/Note selector, difficulty and question-count controls                             |
| 10| Quiz Attempt                  | MCQ options mid-attempt, one option selected                                            |
| 11| Quiz Result                   | Scored result with correct/incorrect highlighting and AI explanations                    |
| 12| Flashcards — Deck List        | Generated decks list with card counts                                                    |
| 13| Flashcards — Flip Card        | The interactive card mid-flip showing front vs back                                      |
| 14| Study Planner                 | Grouped-by-day task list + "Generate AI Weekly Plan" form open                          |
| 15| Attendance Tracker             | Subject-wise percentage bars, one below the 75% warning threshold                        |
| 16| Assignment Reminders           | List of assignments with status dropdown and days-left indicator                         |
| 17| Profile Page                   | Editable profile form pre-filled with the logged-in student's data                        |
| 18| Admin Panel — Stats            | Platform-wide stat cards (students, notes, quizzes, chats)                                |
| 19| Admin Panel — Student Table    | Student management table with active/disable toggle and delete action                     |
| 20| Mobile View                    | Any dashboard screen at ~375px width showing the collapsed sidebar drawer                 |

## Capture tips
- Use consistent seeded demo data (a few notes, one attempted quiz, a
  partially-filled planner) so screenshots look populated, not empty.
- Capture both light and dark mode for at least the Dashboard and one
  feature page to demonstrate requirement #11 (Dark/Light Mode).
- Use browser dev tools' device toolbar (e.g. iPhone 12 Pro preset) for the
  mobile-view screenshot to demonstrate requirement #17 (Mobile Friendly).
