# 📘 Project Abstract

**Title:** AI Powered Student Assistant using Generative AI

**Domain:** Web Development, Artificial Intelligence, Education Technology (EdTech)

## Abstract

College students today juggle lecture notes, assignments, attendance
requirements, and exam preparation across disconnected tools — PDF readers,
notebooks, spreadsheets, and messaging apps. This fragmentation makes it hard
to study efficiently and track academic progress in one place.

This project presents the **AI Powered Student Assistant**, a full-stack web
application built on the MERN stack (MongoDB, Express.js, React, Node.js)
that integrates **Google's Gemini Generative AI** to automate common study
tasks. The system allows students to register securely (JWT-based
authentication), converse with an AI tutor for doubt-solving, upload PDF
lecture notes for automatic text extraction and AI summarization, and
generate multiple-choice quizzes and flashcard decks directly from those
notes or any topic of their choosing. In addition, the platform includes a
study planner (with an AI-assisted weekly plan generator), an attendance
tracker with percentage calculations, and an assignment reminder system —
all visualized through an interactive, Chart.js-powered progress dashboard.

The application follows a modular MVC-inspired backend architecture with
clearly separated models, controllers, routes, and middleware, and a
component-driven React frontend styled with Tailwind CSS, supporting both
light and dark themes and full mobile responsiveness. An administrative
panel allows platform oversight, including student account management and
usage statistics. The system demonstrates practical integration of
Generative AI APIs into a real-world productivity tool, showcasing secure
authentication, RESTful API design, file handling, data aggregation, and
modern responsive UI/UX practices — all directly relevant to both academic
evaluation and industry-standard full-stack development.

**Keywords:** Generative AI, MERN Stack, Gemini API, EdTech, JWT
Authentication, React, MongoDB, Study Assistant, Natural Language Processing
